# Built-in tools

| Tool | Purpose |
|------|---------|
| `memory_get` | Read a value from shared memory |
| `memory_set` | Write a value to shared memory |
| `memory_list` | List memory keys |
| `read_text_file` | Read UTF-8 text within the workspace |
| `write_workspace_text_file` | Atomically write a text file |
| `stat_workspace_path` | File metadata |
| `list_workspace_entries` | Directory listing (flat or recursive) |
| `glob_workspace_files` | Glob patterns under workspace root |
| `analyze_csv` | CSV column and row summaries |
| `run_python_snippet` | Restricted Python execution |
| `web_search_stub` | Offline search placeholder |
| `fetch_url_text` | Bounded HTTP GET |
