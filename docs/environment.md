# Environment variables

| Variable | Description |
|----------|-------------|
| `OPENAI_API_KEY` | API key for live LLM calls |
| `OPENAI_BASE_URL` | Override OpenAI-compatible base URL |
| `OPENAI_MODEL` | Model name (default `gpt-4o-mini`) |
| `MULTI_AGENT_WORKSPACE` | Default workspace for CLI commands |
| `MULTI_AGENT_MAX_TOOL_LOOPS` | Max tool iterations per agent run (1–256, default 12) |
| `MULTI_AGENT_MOCK_LLM` | When `1`/`true`/`yes`, CLI uses MockLLM without `--mock-llm` |
